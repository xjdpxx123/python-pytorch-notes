# python-pytorch-notes

一份面向初学者的 PyTorch 学习笔记，记录深度学习基础知识与 PyTorch 实践过程，涵盖张量、自动求导、神经网络、模型训练与 MNIST 手写数字识别等内容。

## 内容

- 深度学习基础：机器学习、深度学习、数据集、参数与超参数、神经网络基础等

- PyTorch：Tensor、形状、数据类型、设备、张量运算与自动求导等

- 数据处理：MNIST、图像预处理、Dataset、DataLoader、Batch 等

- 神经网络：MLP、激活函数、Softmax、交叉熵、前向传播与反向传播等

- 模型训练：优化器、学习率、参数更新、模型评估与指标等

- 模型保存：state_dict、权重保存与加载、实验可复现性等

- 实践：张量与自动求导实验、MNIST 手写数字识别
