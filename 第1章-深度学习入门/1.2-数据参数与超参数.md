# 1.2-数据参数与超参数

## 1.2.1-数据、参数与中间量

| 类型 | 例子 | 在训练中的作用 |
| --- | --- | --- |
| 数据 | 输入特征 $\mathbf x$、标签 $y$ | 提供学习依据，普通监督训练不会通过参数更新修改它们 |
| 参数 | 权重 $W$、偏置 $\mathbf b$ | 决定模型的映射关系，由优化算法更新 |
| 中间量 | 加权结果 $\mathbf z$、激活输出 $\mathbf a$、预测 $\hat y$ | 根据当前输入和参数重新计算 |
| 训练目标 | 数据损失 $L$、总目标 $J$ | 衡量当前模型表现，为计算梯度提供依据 |
| 超参数 | 学习率 $\eta$、批大小、隐藏层宽度 | 规定模型结构或训练方式，通常根据验证结果选择 |

中间量会随着参数更新而变化，但它们并不是独立保存并由优化器逐一更新的模型参数。例如，更新权重后，下一次前向计算会得到新的预测，而不是直接把上一次的预测当作参数修改。

超参数也不一定始终保持不变。学习率可以按预先设定的调度规则逐步下降，但这种变化仍不同于模型权重按损失梯度进行的更新。

## 1.2.2-常用符号

| 符号 | 含义 |
| --- | --- |
| $N$、$B$ | 数据集样本数、一个批次的样本数 |
| $d$、$m$、$C$ | 输入特征数、一层的输出维度、类别数 |
| $\mathbf x_i$、$y_i$ | 第 $i$ 个样本的输入与目标 |
| $\hat y_i$ | 模型对第 $i$ 个样本的预测 |
| $W$、$\mathbf b$ | 权重矩阵与偏置向量 |
| $\theta$ | 所有待学习参数的统称 |
| $\mathbf z$、$\mathbf a$ | 激活之前的加权结果、激活之后的输出 |
| $\ell_i$ | 单个样本的损失 |
| $L$ | 对一组样本损失求和或求平均得到的数据损失 |
| $J$ | 包含正则化等项的总训练目标 |
| $\eta$、$\lambda$ | 学习率、正则化强度 |

粗体小写字母通常表示向量，大写字母通常表示矩阵，$\mathsf T$ 表示转置，$\mathbb R$ 表示实数集合。例如，$W\in\mathbb R^{m\times d}$ 表示 $W$ 是一个有 $m$ 行、$d$ 列的实数矩阵。

下标需要结合上下文理解：$x_i$ 可能表示第 $i$ 个样本，而 $w_j$ 通常表示一个权重向量中的第 $j$ 个分量。

## 1.2.3-用一个线性模型区分这些量

设模型为 $\hat y=wx+b$，当前有：

$$
x=2,\qquad y=5,\qquad w=1,\qquad b=0
$$

模型得到 $\hat y=2$，平方误差为：

$$
\ell=(\hat y-y)^2=(2-5)^2=9
$$

这里，$x$ 和 $y$ 是数据，$w$ 和 $b$ 是参数，$\hat y$ 和 $\ell$ 是计算结果。如果学习率设为 $\eta=0.1$，它就是训练过程的超参数。优化器随后依据损失对 $w$、$b$ 的梯度更新参数；新的预测需要用更新后的参数重新计算。
