# 2.9-激活函数与梯度问题

激活函数为网络引入非线性。若只堆叠带偏置的线性层，例如：

$$
\mathbf h=\mathbf W_1\mathbf x+\mathbf b_1,
\qquad
\mathbf y=\mathbf W_2\mathbf h+\mathbf b_2,
$$

代入后得到：

$$
\mathbf y
=(\mathbf W_2\mathbf W_1)\mathbf x
+(\mathbf W_2\mathbf b_1+\mathbf b_2).
$$

它仍是一个仿射变换。因此增加这样的层数，并不能得到一般的非线性映射。在线性层之间加入激活函数，才使多层网络能够表示更复杂的关系。

## 2.9.1-常见激活函数

| 函数 | 形式或输出特性 | 梯度与使用特点 |
| --- | --- | --- |
| Sigmoid | $\sigma(x)=1/(1+e^{-x})$，输出在 0 与 1 之间 | 大正值和大负值时导数接近 0，容易饱和 |
| tanh | 输出在 -1 与 1 之间 | 输出以 0 为中心，但两端仍会饱和 |
| ReLU | $\max(0,x)$ | 正区间导数为 1，负区间为 0 |
| Leaky ReLU | 负区间保留固定的小斜率 | 负输入仍可传递非零梯度 |
| PReLU | 负区间斜率可学习 | 比固定斜率形式增加可学习参数 |
| RReLU | 训练时随机选择负区间斜率 | 训练与评估时的行为不同 |
| Maxout | 多个仿射变换结果中的最大值 | 通常需要更多参数与计算 |

本例的隐藏层使用 Sigmoid。它输出的数值虽然位于 0 与 1 之间，但这里表示隐藏特征，不能直接解释为数字类别的概率。最后一层输出未经激活的 logits，再交给交叉熵损失处理。

## 2.9.2-梯度消失与梯度爆炸

反向传播需要把各层的局部导数相乘。对标量链式结构，可以写成：

$$
\frac{\partial L}{\partial h_0}
=\frac{\partial L}{\partial h_n}
\prod_{\ell=1}^{n}\frac{\partial h_\ell}{\partial h_{\ell-1}}.
$$

在多维网络中，对应的是 Jacobian 矩阵的连乘。如果整体连乘使梯度反复缩小，靠近输入的层可能难以更新，称为梯度消失；如果反复放大，则可能产生梯度爆炸。

Sigmoid 的导数为：

$$
\sigma'(x)=\sigma(x)(1-\sigma(x))\leq\frac14.
$$

当输入绝对值很大时，导数还会接近 0。仅考虑 10 个取值为 $1/4$ 的导数因子，乘积就约为 $9.54\times10^{-7}$，说明连续缩小会快速削弱梯度；真实网络还同时包含权重矩阵等因素，不能只凭激活函数的导数判断最终梯度大小。

tanh 的两端也会饱和，换用它不能保证消除梯度消失。ReLU 在正区间不缩小梯度，但负区间的导数为 0，某些单元可能长期不激活；权重矩阵的连乘仍可能放大梯度，因此 ReLU 也不保证避免梯度爆炸。

## 2.9.3-怎样检查训练稳定性

| 现象 | 可以检查的因素 |
| --- | --- |
| 损失几乎不下降，早期层梯度很小 | 激活是否饱和、参数是否参与优化、初始化和输入尺度是否合适 |
| 损失剧烈振荡或出现非有限数值 | 学习率、输入与损失的数值范围、梯度是否过大 |
| 更深的网络反而难以训练 | 梯度传播、初始化、归一化与残差结构是否合适 |

合理初始化、适当的输入尺度和学习率可以改善训练条件；归一化与残差连接也能帮助更深的网络训练。梯度裁剪可限制过大的梯度，但不能代替排查错误的数据或损失计算。

比较 Sigmoid 与 ReLU 时，应分别重新初始化模型和优化器，使用相同数据划分与训练设置，并通过验证集比较。直接替换已经训练好的模型中的激活函数，会改变已有表示，不能据此判断两种激活函数的训练效果。
