# 2.1-PyTorch框架概述

PyTorch 是用于张量计算和构建神经网络的框架。

一个分类模型的训练过程可以写成：

$$
\mathbf X
\xrightarrow{\text{模型 }f_\theta}
\mathbf Z
\xrightarrow{\text{与标签 }\mathbf y\text{ 计算损失}}
L(\mathbf Z,\mathbf y)
\xrightarrow{\text{反向传播}}
\nabla_\theta L
\xrightarrow{\text{优化器}}
\theta_{\text{new}}.
$$

其中 $\mathbf X$ 是一批输入，$\mathbf y$ 是对应标签，$\mathbf Z$ 是模型输出的类别分数，$\theta$ 表示可学习参数。前向传播回答“当前模型预测什么”，反向传播回答“参数怎样影响损失”，优化器根据梯度改变参数。

| 组件 | 作用 | 在手写数字识别中的例子 |
| --- | --- | --- |
| `torch.Tensor` | 表示多维数据，执行数值运算 | 保存图像、标签、权重和类别分数 |
| `torch.autograd` | 根据运算关系计算梯度 | 求损失对各层权重的偏导数 |
| `torch.nn` | 提供网络层、模型容器和损失函数 | 使用 `Linear`、`Sigmoid` 和 `CrossEntropyLoss` |
| `torch.optim` | 按指定规则更新参数 | 使用 Adam 调整权重与偏置 |
| `Dataset` / `DataLoader` | 访问样本并组织批次 | 每次取出一批图像和标签 |
| `torchvision` | 提供计算机视觉数据集、变换和模型 | 加载 MNIST 并转换图像格式 |

定义模型只确定了计算结构；调用模型会得到预测；只有计算损失、反向传播并执行参数更新，模型才完成一次学习。训练结束后，还需要在未参与参数更新的数据上评估，判断模型是否学到了可推广的规律。
