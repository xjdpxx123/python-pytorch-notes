# 1.11-PyTorch概念对照

神经网络的数学过程可以分成数据表示、前向计算、目标计算、求导和参数更新。PyTorch 为这些过程提供对应的对象和操作。

| 数学概念 | PyTorch 中的对应内容 | 需要关注的问题 |
| --- | --- | --- |
| 输入、权重、输出 | `Tensor` | 形状、数据类型和设备是否匹配 |
| 仿射变换 $XW^\mathsf T+b$ | `nn.Linear` | 输入与输出维度是否正确，是否包含偏置 |
| 非线性激活 | `nn.ReLU`、`nn.Sigmoid` 等 | 激活的位置与任务是否匹配 |
| 模型结构与前向计算 | `nn.Module`、`forward` | 各层怎样组合，输出表示什么 |
| 分类原始分数 | logits | 与概率、类别索引的区别 |
| 分类交叉熵 | `nn.CrossEntropyLoss` | 输入应为 logits，目标格式需要匹配 |
| 链式求导 | `loss.backward()` | 梯度会累积，需明确清除时机 |
| 参数梯度 | 参数的 `.grad` | 与参数值区分，检查是否确实得到梯度 |
| 参数更新 | 优化器的 `step()` | 使用已有梯度修改参数 |
| 训练与评估行为 | `model.train()`、`model.eval()` | 部分层在两个阶段的计算行为不同 |
| 关闭梯度记录 | `torch.no_grad()` | 在普通评估中避免构建不需要的计算图 |

## 1.11.1-一个批次的训练流程

以 10 类分类为例，假设一个批次有 $B$ 个样本：

| 阶段 | 得到的量 | 典型形状或含义 |
| --- | --- | --- |
| 准备数据 | 输入、类别标签 | 输入包含批次维度，标签通常为 `(B,)` |
| 模型前向计算 | logits | `(B, 10)` |
| 计算平均交叉熵 | loss | 一个标量 |
| 反向传播 | 各参数的梯度 | 每个梯度的形状与对应参数一致 |
| 优化器更新 | 新参数 | 参数形状不变，数值改变 |

标签的形状为 `(B,)`，是因为每个样本只保存一个类别索引。输出的形状为 `(B, 10)`，是因为每个样本需要对 10 个候选类别分别打分。

`backward()` 不会自动调用优化器，`step()` 也不会替模型重新进行前向计算。处理下一个批次时，需要再次用新参数计算预测和损失。

## 1.11.2-评估涉及两个独立设置

`model.eval()` 设置模型的评估行为，例如影响 Dropout 和 BatchNorm；`torch.no_grad()` 控制是否记录梯度计算。两者用途不同，因此普通评估通常同时使用。

仅设置评估模式不会自动关闭梯度，关闭梯度也不会自动切换模型行为。
