# 2.10-模型评估与指标

模型评估使用已经确定的参数，对一组数据计算预测结果和指标。评估阶段不执行参数更新，但仍需要正确设置模型模式、关闭不必要的梯度记录，并按照样本数量汇总结果。

## 2.10.1-评估模式与梯度记录

`model.train()` 和 `model.eval()` 控制模块的训练或评估行为。例如，Dropout 在训练时随机丢弃部分激活，评估时停止随机丢弃；采用默认配置的 BatchNorm 在训练与评估时使用统计量的方式不同。本例只有 Linear、Flatten 和 Sigmoid，这些层在两种模式下的计算行为相同，但保留模式切换便于后续扩展网络。

模型模式和梯度记录是两个独立设置：

| 设置 | 作用 |
| --- | --- |
| `model.eval()` | 切换会区分训练和评估状态的模块行为 |
| `torch.no_grad()` | 在指定范围内停止记录用于反向传播的计算图 |
| `torch.inference_mode()` | 用于推理，进一步减少部分自动求导相关开销 |

`eval()` 不会自动关闭梯度记录，`no_grad()` 也不会自动切换模型模式。常见的评估过程同时使用 `eval()` 和 `no_grad()`，然后遍历验证集或测试集，累计损失与正确样本数。评估后如果继续训练，需要再次调用 `model.train()`。

## 2.10.2-准确率与平均损失

设数据集中共有 $N$ 个样本，预测类别为 $\hat y_i$，真实类别为 $y_i$，准确率为：

$$
\mathrm{Accuracy}
=\frac{1}{N}\sum_{i=1}^{N}\mathbf1[\hat y_i=y_i].
$$

其中 $\mathbf1[\cdot]$ 在条件成立时取 1，否则取 0。例如 10,000 张图片中预测正确 9,500 张，准确率就是 95%。

本例的交叉熵未设置类别权重，也未忽略标签，每个 batch 的损失是样本损失均值。设第 $b$ 批有 $n_b$ 个样本，平均损失为 $L_b$，整个数据集的平均损失应为：

$$
\overline L
=\frac{\sum_{b=1}^{M}n_bL_b}{\sum_{b=1}^{M}n_b}.
$$

如果一批 64 个样本的均值为 0.2，另一批 16 个样本的均值为 0.8，那么整体均值为：

$$
\frac{64\times0.2+16\times0.8}{80}=0.32.
$$

直接平均两个 batch 的均值会得到 0.5，相当于给小批次中的每个样本更高权重。同理，准确率应累计正确样本数后除以实际评估样本数，而不是无条件平均每个 batch 的准确率。若损失使用了类别权重或忽略标签，平均的分母也要按相应定义调整。

## 2.10.3-怎样理解评估结果

| 指标或观察 | 可以回答的问题 |
| --- | --- |
| 平均损失 | 模型给真实类别分配的概率是否在改善 |
| 整体准确率 | 有多少样本的最终类别预测正确 |
| 各类别召回率（各类别识别正确率） | 哪些真实类别更容易识别错误 |
| 混淆矩阵 | 某个真实类别经常被误判成哪个类别 |
| 错误样本图像 | 错误是否与书写歧义、数据质量或特定图像特征有关 |

各类别召回率表示真实标签属于该类的样本中，预测正确的比例，也可称为各类别识别正确率。计算类别 $k$ 的召回率时，分母为真实标签属于该类的样本总数，分子为其中预测正确的数量。混淆矩阵需要明确轴的含义；可以约定行表示真实类别、列表示预测类别，此时主对角线表示预测正确的样本数。

准确率只关心最大分数对应的类别，损失还反映真实类别的预测概率，因此两者不一定同步变化。训练指标是在参数不断更新时累计的，验证指标则是在每轮结束后的固定参数上计算的，比较时应注意计算条件。短暂波动不必然代表程序错误，应结合多轮趋势和具体错误样本判断。
