# 2.5-MLP网络与前向传播

多层感知器（Multi-Layer Perceptron，MLP）由多个全连接层与非线性激活函数组成。本例将每张图片展平成 784 维向量，再通过两个隐藏层提取特征，最后输出 10 个类别分数。

```mermaid
flowchart LR
    A["图片 B × 1 × 28 × 28"] --> B["Flatten：B × 784"]
    B --> C["Linear 784 → 128"]
    C --> D[Sigmoid]
    D --> E["Linear 128 → 256"]
    E --> F[Sigmoid]
    F --> G["Linear 256 → 10"]
    G --> H["logits：B × 10"]
```

## 2.5.1-线性层的计算与参数数量

对一批输入 $\mathbf X\in\mathbb R^{B\times d_{\text{in}}}$，带偏置的线性层计算：

$$
\mathbf Y=\mathbf X\mathbf W^\top+\mathbf b,
\qquad
\mathbf Y\in\mathbb R^{B\times d_{\text{out}}}.
$$

`nn.Linear(in_features,out_features)` 把权重存为 `[out_features,in_features]`，偏置存为 `[out_features]`。同一组权重应用到批次中的每个样本，偏置也会加到每个样本的输出上。批次大小影响一次处理的样本数量，不影响模型参数数量。

| 层 | 输入与输出 | 包含偏置的参数数量 |
| --- | --- | ---: |
| `Linear(784,128)` | `[B,784]` → `[B,128]` | $784\times128+128=100480$ |
| `Linear(128,256)` | `[B,128]` → `[B,256]` | $128\times256+256=33024$ |
| `Linear(256,10)` | `[B,256]` → `[B,10]` | $256\times10+10=2570$ |
| 合计 | | **136,074** |

`Flatten` 只调整形状，Sigmoid 只执行固定的非线性变换，两者都没有可学习参数。最后一层直接输出 logits，供交叉熵损失使用，不在输出后额外添加 Sigmoid 或 Softmax。

## 2.5.2-模型定义与前向传播

自定义模型通常继承 `nn.Module`。构造函数 `__init__` 负责建立并注册各层，`forward` 负责描述输入依次经过哪些运算。

| 阶段 | 发生的事情 |
| --- | --- |
| 构造模型 | 创建线性层，并初始化权重和偏置 |
| 前向传播 | 使用当前参数计算预测结果 |
| 反向传播 | 计算损失对参数的梯度 |
| 优化器更新 | 根据梯度修改参数值 |

普通 `nn.Linear` 在构造时初始化参数；反复调用同一个模型的 `forward` 会使用同一组参数。若在每次前向传播时重新创建线性层，参数就不能按预期持续学习，优化器也可能无法管理这些临时创建的参数。

训练与推理时通过 `model(X)` 调用模型。它会执行 `forward`，同时保留模块调用机制提供的 hooks 等功能；直接调用 `model.forward(X)` 会绕开这部分机制。

MLP 将图像像素作为一组特征处理，全连接结构不会像卷积层那样显式利用相邻像素的局部连接关系。增加全连接层的宽度并不自动保证更好的图像识别效果。
